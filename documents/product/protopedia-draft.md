## 概要説明（200〜400字程度）

前任者の退職や他社からの引き継ぎで起きる「ドキュメントの陳腐化」「手動変更によるIaC崩壊」。  
こうした**引き継ぎシステムの負の遺産**を、AI エージェントが自律的に再生するのが PhoenixDevOps です。

ソースコードと古い既存ドキュメントをアップロードするだけで、AI が以下を自動生成します。

- **真の設計書**: ソースコードから抽出した現在の実装仕様
- **ドキュメント差分レポート**: 古いドキュメントと実装の食い違いを可視化
- **SSOT（単一情報源）仕様書**: DB・ビジネスロジック・APIを統合した包括的な仕様書
- **インフラ構成仕様書**: IaC ファイルからインフラ・セキュリティ設計を抽出

「現状が分からないから触れない」状態から、「根拠のある設計書がある」状態へ。  
引き継いだ初日から安全にコードを改修できるチームを目指します。

## こだわりポイント

### 1. マルチエージェント構成で精度を上げる

単一の LLM プロンプトに全コードを流し込むアプローチでは、大規模コードベースの解析精度に限界があります。  
PhoenixDevOps では解析を **5つの専門エージェント** に分割し、最後に統合エージェントが SSOT 仕様書として統合します。

| エージェント | 担当領域 |
|---|---|
| ソースコード解析 | ファイル構成・ルーティング・依存関係 |
| DBスキーマ解析 | テーブル定義・リレーション・マイグレーション |
| ビジネスロジック解析 | コアドメインのロジック・バリデーション |
| API 仕様解析 | エンドポイント・リクエスト/レスポンス・認証 |
| インフラ解析 | IaC・クラウド構成・セキュリティ設計 |
| SSOT 合成 | 上記全エージェントの出力を統合した単一仕様書の生成 |

### 2. "IaC崩壊を自分たちが再現しない" 徹底ぶり

「ドキュメントと実態の乖離を解決するプロダクト」を作るチームが、同じ問題を自分たちで引き起こさない。  
GCP リソースはすべて Terraform で管理し、コンソールからの手動変更を禁止。  
CI/CD（GitHub Actions + Workload Identity 連携）で計画・適用を自動化し、**プロダクトの思想をインフラ運用で体現**しています。

### 3. AI エージェントの作業環境自体を git 管理する「ハーネス」設計

Claude Code をはじめとする AI エージェントの指示・設定（プロンプト・コマンド）を `.claude/` に集約し、git 管理対象として全員が同じ前提でエージェントを動かせる環境を構築しました。  
「チームで AI エージェントを使う」際のベストプラクティスを実践しています。

## 技術スタック

| カテゴリ | 技術 | 用途 |
|---|---|---|
| AI エンジン | Gemini API (gemini-3.1-flash-lite / Vertex AI 経由) | コード解析・仕様生成 |
| バックエンド | Cloud Functions Gen2 (Node.js / TypeScript) | API・解析ワーカー |
| 非同期処理 | Cloud Tasks | 解析ジョブのキューイング |
| DB | Firestore | 解析ジョブ状態管理 |
| ストレージ | Cloud Storage | ソースコード/成果物の保存 |
| IaC | Terraform | GCP リソース管理 |
| フロントエンド | React / Vite / TypeScript | Web UI |
| CI/CD | GitHub Actions + Workload Identity 連携 | Terraform Plan/Apply の自動化 |
| 認証 | Workload Identity Federation | 長期キー不要の鍵レス認証 |
| AI 開発環境 | Claude Code (claude-sonnet-4-6) | ハーネス設計・コーディング支援 |

## システム構成図（簡略版）

```
ユーザー → Web画面 → Cloud Functions(HTTP API)
                          │
                          ├─ Cloud Storage（ソースコード/ドキュメント保存）
                          ├─ Firestore（ジョブ状態管理）
                          └─ Cloud Tasks（ジョブキュー）
                                    │
                          Cloud Functions（解析ワーカー）
                                    │
                          Gemini API ×5エージェント
                                    │
                          Cloud Storage（成果物保存）
                                    │
                    ← Web画面（成果物表示・ダウンロード）
```
