# 必須条件

ハッカソンの必須条件に基づき、使わないといけない技術スタックは以下の2つのカテゴリに分かれており、それぞれのカテゴリから少なくとも1つ以上を選択して使用する必要があります。

## 1. 使用しなければならないGoogle Cloud アプリケーション実行プロダクト（以下のいずれか1つは必須）

- App Engine または Google Compute Engine
- Google Kubernetes Engine (GKE)
- Cloud Run または Cloud Functions (旧 Cloud Functions)
- Cloud TPU または Cloud GPU

## 2. 使用しなければならないGoogle Cloud AI 技術（以下のいずれか1つは必須）

- Gemini Enterprise Agent Platform（旧Vertex AI）
- Gemini API
- Gemma、Imagen、または Agent Builder
- ADK (Agents Development Kit)
- Speech-to-Text または Text-to-Speech API
- Vision AI API または Natural Language AI API
- Translation AI API

なお、必須ではありませんが、任意の技術として Flutter、Firebase、Veo、Elasticsearch などを使用することも可能です。
